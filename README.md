# Vietnam - TT99/2025 Financial Statements

Odoo 19 module by Tricasia: B01-DN, B02-DN, B03-DN (direct and indirect) under Circular 99/2025/TT-BTC, on the core `l10n_vn` chart. Every line has an editable formula; on-screen report with live filters, multi-period comparison and variance; PDF and Excel output; drill-down to journal items.

- Formula engine: `models/engine.py`
- Report definitions: `data/*.xml`, generated by `tools/tt99/gen_reports.py` in [Tricasia/odoo-dev](https://github.com/Tricasia/odoo-dev) — do not edit the XML by hand.
- Documentation (tables, fields, formula language, flows): `docs/tt99/TT99_Documentation.pdf` in odoo-dev.

Tests: `odoo -d <tmp_db> -i l10n_vn_tt99_reports --test-tags /l10n_vn_tt99_reports --stop-after-init`
